# Paddle v1.0 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在不改变当前产品形态、文案、价格和功能定位的前提下，把 credits、workspace 订阅、dating profile review unlock 全部接入 Paddle，并准备 `paddle_v1.0` 审核材料。

**Architecture:** 新增统一 billing 层作为 Stripe/mock 与 Paddle 的隔离层；前端只调用 `/api/payments/checkout`，Paddle webhook 负责幂等交付。数据库新增通用订单、事件、credit ledger、subscriptions 表，同时保留旧 `transactions` 与 `profile_review_orders` 兼容现有页面查询。

**Tech Stack:** Next.js 14 App Router、TypeScript、Clerk、Supabase、Paddle.js v2、Paddle API、Node `node:test`。

1. 登录 Paddle Dashboard。
2. 创建 live/sandbox products 与 prices，并把 price id 写入部署环境变量。
3. 创建 client-side token、server API key、webhook destination。
4. 配置 payout settings。
5. 提交 domain/website approval。
6. 提交产品审核材料 `docs/paddle_v1.0_审核提交材料.md`。
7. 审核通过后切换生产环境 `PADDLE_ENVIRONMENT=production`。
